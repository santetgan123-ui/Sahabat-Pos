## 📖 About The Project

**Sahabat Pos** is a web-based service platform designed to streamline operational tasks. This project was developed to create an efficient system for managing service data, featuring a user-friendly interface and a dedicated admin panel for content management.

### ✨ Key Features

* **Admin Dashboard**: A secure panel for administrators to manage site content and user data.
* **Photo Gallery**: Dynamic gallery feature to showcase service documentation or portfolio.
* **Service Listing**: Clear presentation of available services for users.
* **Responsive Design**: Optimized for viewing on both desktop and mobile devices.

## 🛠️ Built With

This project is built using the following technologies:

* **Frontend**: HTML5, CSS3, JavaScript
* **Backend**: PHP (Native)
* **Database**: MySQL
* **Server**: Apache/Nginx (XAMPP/Laragon)

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites

* Web Server (XAMPP, WAMP, or Laragon)
* Web Browser (Chrome, Firefox, etc.)

### Installation

1.  **Clone the repo**
    ```sh
    git clone [https://github.com/santetgan123-ui/Sahabat-Pos.git](https://github.com/santetgan123-ui/Sahabat-Pos.git)
    ```
2.  **Move to htdocs**
    Move the project folder to your local server directory (e.g., `C:/xampp/htdocs/`).
3.  **Database Setup**
    * Open `phpMyAdmin`.
    * Create a new database named `sahabat_pos`.
    * Import the `database.sql` file located in the `db/` folder of this project.
4.  **Configure Connection**
    * Open `config.php` (or your database connection file).
    * Adjust the database credentials (username, password, db name).
5.  **Run the Project**
    Open your browser and go to `http://localhost/Sahabat-Pos`.
